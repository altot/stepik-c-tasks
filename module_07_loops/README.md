ОЧЕНЬ краткая шпаргалка по материалу урока

Инструкция switch  переключает выполнение программы на определённую ветку кода в зависимости от значения управляющего выражения.
Общий синтаксис:

switch (управляющее_выражение) {
    case метка_1: набор_инструкций_1
    case метка_2: [набор_инструкций_2]
    case метка_3: [набор_инструкций_3]
    case метка_4: [набор_инструкций_4]
    //...
    [default: набор_инструкций_по-умолчанию]
}

                      
                  

Квадратными скобками обозначены необязательные части.
Ограничения:

    Управляющее выражение: только целочисленные или символьные переменные, либо целочисленные выражения
    Метки: целые числа и символы. Должны быть уникальными внутри одной инструкции switch
    При сравнении значения управляющего выражения и меток учитывается тип данных. Символ '1' это не то же самое, что целое число 1 .

Как работает switch:

    Вычисляет, если необходимо, управляющее выражение и сравниваем полученное значение с метками.
    Если есть совпадение с меткой, то выполняются все инструкции, записанные после этой метки, до ближайшей инструкции break или до конца инструкции switch (до закрывающей фигурной скобки })
    Если нет подходящей метки, то выполняются ветка default (если она есть).

 
Нюансы:
Сквозное выполнение (проваливание, fallthrough)

    если в ветке отсутствует break, то происходит "проваливание" в следующую  ветку
    можно использовать для упрощения и оптимизации кода программы

Порядок веток

    порядок case произвольный (default обычно в конце)
    группируйте похожие case для оптимизации

Инструкция break

    используется для предотвращения проваливания
    выходит только из текущего switch

Совет: Сначала добавляем во все ветки, потом убираем там, где требуется сделать "проваливание".
Вложенные инструкции switch

    внутри ветки case можно снова использовать switch
    метки во вложенных switch могут повторяться
    break выходит только из текущего switch

Примеры:

char ch = 'D';

switch(ch) {
    case 'A': // проваливание
    case 'a': // код ниже выполнится для обоих случае
        printf("A selected!\n");
        break;
    default: 
        printf("A not selected!\n");
        break;
}


int num = 5;

switch (num % 3) { // внешняя инструкция switch
	case 0:
		switch (num % 2) { // вложенная инструкция switch
			case 0:
				printf("GOOD!\n");
				break; // выходим из вложенной switch
			case 1:
				printf("BAD!\n");
				break; // выходим из вложенной switch
		}
		break; // выходим из внешней инструкции switch
	case 1: // проваливание
	case 2: 
		printf("BAD!\n");
		break;
}
